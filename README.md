## Installation

1. Install.
2. Nothing happens.

That's the whole workflow.

### Manual install

1. Download `main.js` and `manifest.json` from the latest release.
2. Put them in `<your vault>/.obsidian/plugins/nothing/`.
3. Restart Obsidian and enable **Nothing** under *Settings → Community plugins*.
4. Observe that nothing has changed. Success.
